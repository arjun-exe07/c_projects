# Unit Converter

A menu-driven Unit Converter built using C.

## Features

- Celsius ↔ Fahrenheit
- Kilometers ↔ Miles
- Kilograms ↔ Pounds
- Menu-driven interface
- Continuous conversion until exit

## Concepts Used

- Functions
- Switch Statements
- Loops
- User Input
- Floating Point Calculations

## How to Run

gcc unit_converter.c -o converter

./converter

## Learning Outcomes

- Creating reusable functions
- Building menu-driven applications
- Performing unit conversions
- Working with floating-point numbers
