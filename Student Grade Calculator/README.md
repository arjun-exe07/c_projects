# Student Grade Calculator

A simple C program that calculates the total marks, average marks, and grade of a student based on marks entered for multiple subjects.

## Features

* Accepts marks for multiple subjects
* Calculates total marks
* Calculates average marks
* Assigns a grade based on average
* Displays student result summary

## Concepts Used

* Arrays
* Loops
* Functions
* Conditional Statements (`if-else`)
* User Input (`scanf`)
* Basic Mathematical Calculations

## How to Run

### Compile

```bash
gcc main.c -o grade_calculator
```

### Execute

```bash
./grade_calculator
```

## Sample Output

```text
Enter number of subjects: 5

Enter marks for Subject 1: 85
Enter marks for Subject 2: 90
Enter marks for Subject 3: 78
Enter marks for Subject 4: 88
Enter marks for Subject 5: 92

Total Marks: 433
Average: 86.60
Grade: B
```

## Grade Criteria

```text
90 - 100 : A
80 - 89  : B
70 - 79  : C
60 - 69  : D
Below 60 : F
```
