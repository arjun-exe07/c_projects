# 📦 Inventory Management System

A console-based Inventory Management System built in C to manage product records using structures and arrays.

## Features

* Add new products
* Display all products
* Search products by Product ID
* Sell products and automatically reduce stock
* Restock existing products
* Prevent duplicate Product IDs
* Validate product price and quantity inputs
* Menu-driven user interface

## Product Information

Each product stores:

* Product ID
* Product Name
* Price
* Quantity in Stock

## Concepts Used

* Structures (`struct`)
* Arrays
* Functions
* Loops
* Conditional Statements
* Input Validation
* Modular Programming

Compile the program using GCC:

```bash

```

